# Zepto SQL Data Analysis Project

## Project Overview
This project focuses on analyzing Zepto e-commerce inventory data using MySQL.  
The goal was to perform data cleaning, exploration, and business analysis to generate meaningful insights from product-level data.

---

## Dataset Information
- Dataset contains 3732 Zepto products
- Includes:
  - Product categories
  - MRP
  - Discount percentage
  - Selling price
  - Stock availability
  - Product quantity and weight

---

## Analysis Performed

### Data Exploration
- Total product count
- Unique categories
- Product distribution by category

### Data Cleaning
- NULL value detection
- Duplicate product checks
- Invalid price checks

### Business Analysis
- Top expensive products
- Most discounted products
- Revenue potential by category
- Out-of-stock product analysis
- Average discount by category

### Advanced SQL Queries
- CASE statements
- Price bucket segmentation
- Inventory stock analysis
- Aggregations using GROUP BY
- Sorting and filtering using ORDER BY and WHERE
